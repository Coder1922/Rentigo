## 📖 About the Project

**Rentigo** is a comprehensive, full-stack car rental management system designed to simplify the vehicle renting process for customers, car agencies (vendors), and platform administrators. Whether you are browsing for a weekend SUV or managing a fleet of sedans across multiple cities, Rentigo provides a unified ecosystem to handle inventory, check real-time availability, process secure bookings, and oversee operations.

Built with modern web technologies, it ensures a fast, responsive, and frictionless experience across all devices.

## ✨ Core Architecture & Portals

The application is structured into distinct, role-based environments to ensure secure and streamlined operations:

*   **Customer Portal:** A dedicated interface for end-users to search for cars, filter by vehicle type, book rentals, and view their reservation history.
*   **Agency Portal:** Tools tailored for partner car agencies to manage their fleet (add/edit/remove vehicles), track active rentals, and manage dynamic pricing.
*   **Admin Portal:** A centralized dashboard for platform administrators to monitor platform-wide metrics, approve agencies, and manage user accounts.
*   **Auth Portal:** Secure authentication routing and user access management.

## 📍 Supported Regional Hubs

Rentigo features a scalable, multi-location architecture. Currently, the platform is configured to serve specific regional hubs in Gujarat:
*   Ahmedabad
*   Rajkot
*   Surat
*   Vadodara

## ⚙️ Key Features

*   **Smart Vehicle Search & Filtering:** Find the perfect car based on location, price range, vehicle category (SUV, Sedan, Hatchback, Luxury), and pickup/drop-off dates.
*   **Real-Time Availability:** Prevent double-booking with live calendar sync and instant availability checks.
*   **Dynamic Fleet Management:** Agencies can add vehicles with unique identifiers (e.g., license plates), rich image uploads, mileage limits, and detailed descriptions.
*   **Automated Notifications:** Send instant confirmation emails and upcoming reservation reminders to customers.
*   **Order Tracking:** Monitor the status of every rental from *Reserved* ➡️ *Checked-Out* ➡️ *Returned*.
